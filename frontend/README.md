# Chatbot

Responsive React frontend + Node.js/SQLite backend.

## Default login

- Username: `john`
- Password: `password123`

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start backend API (port 3001):
   ```bash
   npm run server
   ```
3. In another terminal, start frontend (port 5173):
   ```bash
   npm run dev
   ```

The Vite dev server proxies `/api/*` requests to the backend.
